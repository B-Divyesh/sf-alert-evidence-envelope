Privacy notice

How this relay handles data

The self-hosted core transforms incident data without retaining raw alert bodies or fetched logs.

What the relay stores

SQLite stores route settings and the latest 20 delivery records.

Each record contains an envelope ID, service, state, query fingerprint, time, item count, and byte count.

The relay does not store inbound bodies, evidence excerpts, bearer tokens, or license tokens.

Where secrets live

The relay reads configured secrets from its environment or protected files on the server.

Source and destination URLs may be stored in SQLite. License tokens and paid presets are stored in your browser.

How the demo is separated

SQLite stores each demo session ID and expiry time for up to 24 hours. It never stores the sample alert or envelope.

Network requests

The relay contacts only endpoints configured by its operator.

License verification sends the stored token to Sociobot in an authorization header. The token is never put in a URL. The browser waits 24 hours after each attempt.

This site uses no analytics, advertising cookies, third-party scripts, or hosted fonts.

Control and deletion

The operator controls SQLite and browser storage. Remove the database or clear site data to delete them.

Clear browser site data to remove a stored license token and local presets.
